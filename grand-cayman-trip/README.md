# Grand Cayman Trip

An interactive itinerary for a stay at the Caribbean Club on Seven Mile Beach, Grand Cayman.

**Live site:** https://hungryheels.github.io/grand-cayman-trip/

## What's on it
- **Itinerary**: a day-by-day planner (arrival date, nights, morning/afternoon/evening plans). Saved in the browser on each device.
- **The Club**: suites, amenities, concierge services and contacts for the Caribbean Club.
- **Map**: interactive island map (Leaflet + OpenStreetMap/CARTO tiles) with drive times from the Club, search, filters, day routes and Google Maps directions.
- **Dining**: 42 top-rated restaurants with search and style filters, plus a "Restaurants & menus you want" form.
- **Explore**: top-rated activities, all pinned on the map.

## Editing
- Restaurants, activities and the suggested plan live in `data.js`.
- Page text lives in `index.html`; styles in `styles.css`; behavior in `script.js`.
- No build step. Push to `main` and GitHub Pages redeploys in about a minute.
